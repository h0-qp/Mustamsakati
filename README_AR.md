# مستمسكاتي — Mustamsakati

تطبيق محفظة مستمسكات وبطاقات، بالتصميم المعتمد (v3): واجهة داكنة عصرية،
بطاقات كاملة بحجم بطاقة حقيقية، لون مميز واحد (أخضر ليموني)، وقلب البطاقة
في شاشة التفاصيل.

## شنو يسوي التطبيق

- حفظ المستمسكات والبطاقات: عنوان، تصنيف (شخصية / سيارة / دراسة / معاملات)،
  تاريخ نفاد، حقول إضافية اختيارية (مخفية أو ظاهرة)، صورة أمامية (مطلوبة)
  وخلفية (اختيارية).
- الرئيسية تعرض المستمسكات كبطاقات ملوّنة، مرتبة: المثبت أولاً ثم الأقرب نفاداً،
  مع كبسولة «باقي N يوم»، وبحث وفلترة بالتصنيفات.
- شاشة تفاصيل: قلب البطاقة (أمامي/خلفي)، عدّاد أيام كبير مع شريط تقدّم،
  إظهار الحقول المخفية ونسخها، صور مموّهة تتوضح بضغطة، تثبيت، تعديل، حذف.
- تصدير أي مستمسك إلى PDF (الحقول المخفية مقنّعة ما لم تُظهَر قبل التصدير).
- إعدادات: تنبيهات النفاذ، قفل التطبيق برمز PIN (محفوظ مشفّراً بـ pbkdf2،
  مو نص صريح)، تبديل اللغة عربي/English، نسخة احتياطية ZIP (تصدير واستيراد).
- كل البيانات محلية على الجهاز فقط — ماكو حساب ولا سيرفر.

ملاحظات صريحة عن حدود هذه النسخة (Flet):
- ماكو بصمة إصبع حقيقية — القفل برمز PIN فقط.
- ماكو OCR (قراءة تلقائية من الصورة) في هذه النسخة.
- تمويه الصور يتم بطبقة ضبابية فوق الصورة (Backdrop blur) لأن Flet لا يوفر
  فلتر تمويه مباشر على الصور.
- النص العربي داخل PDF يُرسم بخط DejaVu عند توفره؛ تشكيل اتجاه النص العربي
  داخل PDF محدود بدون مكتبات تشكيل إضافية.

## التشغيل محلياً (للمعاينة على الكمبيوتر)

```bash
cd mustamsakati_app
pip install -r requirements.txt
flet run main.py
```

## مكان البيانات

- مجلد البيانات: متغير البيئة `MUSTAMSAKATI_DATA`، وبدونه `./data`
  (ملف `data.json` + مجلد `images/` للصور + مجلد `exports/` لملفات PDF
  الاحتياطية عند تعذّر حفظ الحوار).
- الاختبارات الأساسية (بدون واجهة): `python test_core.py`

## بناء الـ APK عبر GitHub Actions

1. أنشئ مستودعاً جديداً على GitHub بنفسك (حسابك)، وارفَع محتويات هذا
   المجلد إليه. (تطبيق Muse على GitHub ما يقدر ينشئ مستودعات.)
2. من تبويب **Actions** شغّل workflow باسم **Build Mustamsakati APK**
   (أو ادفع إلى فرع `main` فينطلق وحده).
3. بعد نجاح البناء، حمّل الأرتيفاكت **Mustamsakati-APK** من صفحة التشغيل،
   بداخله ملف الـ APK الجاهز للتثبيت.

ملاحظة: إذا رفض GitHub رفع ملف الـ workflow بسبب صلاحيات، ارفع ملف
`.github/workflows/build-apk.yml` بنفسك من واجهة GitHub (نفس ما صار
سابقاً مع NovaSales).

## بنية المشروع

- `main.py` — واجهة Flet كاملة (الرئيسية، التفاصيل، الإضافة/التعديل، الإعدادات، القفل).
- `core.py` — منطق مستقل عن الواجهة: التخزين JSON، CRUD، حساب الأيام، PIN، PDF، النسخ الاحتياطي.
- `test_core.py` — اختبارات core (تخزين، ترتيب، أيام، PIN، PDF، نسخ احتياطي).
- `assets/icon.png` — أيقونة التطبيق (تتولد من `make_icon.py`).
- `pyproject.toml` + `requirements.txt` — إعدادات Flet والاعتماديات.
